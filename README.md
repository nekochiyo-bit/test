# ブロックパズル

ブラウザで遊べるテトリス風の落ち物パズルゲームです。外部ライブラリを使用せず、純粋なHTML/CSS/JavaScriptのみで実装されています。

## 特徴

- 外部依存なし（CDN不要）
- レスポンシブデザイン（PC/スマホ対応）
- タッチ操作対応
- 7種類のブロック（I, O, T, S, Z, J, L）
- 7バッグランダム生成システム
- スコア・レベル・ライン消去システム
- レベルアップで落下速度が上昇
- 一時停止機能

## 遊び方

### キーボード操作（PC）

| キー | 操作 |
|------|------|
| ← → | 左右移動 |
| ↑ | 回転（時計回り） |
| ↓ | ソフトドロップ（速く落とす） |
| Space | ハードドロップ（一気に落とす） |
| P | 一時停止/再開 |

### タッチ操作（スマホ/タブレット）

画面下部に表示されるボタンで操作できます。

- ← → ボタン：左右移動
- 回転ボタン：ブロックを回転
- ↓ ボタン：ソフトドロップ
- ドロップボタン：ハードドロップ

## スコアリング

- ライン消去
  - 1ライン：100点 × レベル
  - 2ライン：300点 × レベル
  - 3ライン：500点 × レベル
  - 4ライン：800点 × レベル
- ハードドロップ：落下距離1マスごとに2点

## レベルシステム

10ライン消去するごとにレベルが1上がります。レベルが上がると、ブロックの落下速度が速くなります。

## ローカルで遊ぶ

1. リポジトリをクローン
```bash
git clone https://github.com/nekochiyo-bit/test.git
cd test
```

2. index.htmlをブラウザで開く
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

または、index.htmlをブラウザにドラッグ&ドロップして開くこともできます。

## GitHub Pagesで公開する

1. GitHubリポジトリの「Settings」タブを開く

2. 左メニューから「Pages」を選択

3. 「Source」で以下を設定：
   - Branch: `claude/block-puzzle-game-zgJa7`（または公開したいブランチ）
   - Folder: `/ (root)`

4. 「Save」をクリック

5. 数分後、以下のURLでアクセス可能になります：
   ```
   https://nekochiyo-bit.github.io/test/
   ```

### 注意事項

- GitHub Pagesは静的ファイルのみをホスティングします
- このゲームは完全にクライアントサイドで動作するため、GitHub Pagesで問題なく動作します

## 技術仕様

- **盤面サイズ**: 10列 × 20行
- **ブロックサイズ**: 30×30ピクセル
- **描画方式**: HTML5 Canvas
- **ランダム生成**: 7バッグシステム（全7種のブロックが均等に出現）
- **回転システム**: 壁蹴り機能付き
